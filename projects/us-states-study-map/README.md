# 美国各州学习地图

一张面向中文学习者的中英双语美国五十州互动学习地图。

## 功能

- 点击州查看英文名、缩写、中文名和所属区域
- 英文州名语音朗读
- 随机找州小测验与实时计分
- 州缩写显示/隐藏
- 键盘与触摸操作支持
- 适合打印的横向地图版式

## 本地运行

```bash
npm install
npm run dev
```

## 构建

```bash
npm run build
```

## GitHub Pages

推送到 `main` 分支后，GitHub Actions 会自动构建并发布公开网站：

https://snowm243.github.io/us-states-study-map/

```bash
npm run build:pages
```
